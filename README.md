# Product Catalog

## Tech Stack
- Swift
- UIKit
- Combine
- URLSession
- SkeletonView

## Architecture
- MVVM + Clean Architecture

## Features
- Products list (Grid & List)
- Pagination (7 items per request)
- Product details screen
- Stretchy header image
- Loading & error states
- Internet connection handling

## Testing
- Unit Tests
